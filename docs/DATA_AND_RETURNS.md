# 数据与收益口径

本主题规定事实来源、估值、收益、汇兑与分类的解释。规则适用于对应业务链路；能力启用按对应功能 PR 的发布记录及实际配置核对，验收以用户明确证据为准。

## 事实与展示

原始资料 → 业务事实 → 当前状态/资产主数据/统一引擎 → API → 前端。页面、临时 YAML 和旧分类接口不得成为新的事实来源。

| 对象 | 职责 |
| --- | --- |
| pams_cashflow_fact | 收支、内部划转、投资资金进出及现金收益 |
| pams_investment_trade_fact | 买卖、分红、费用、换汇和投资账户资金事件 |
| pams_holdings_snapshot | 当前持仓快照，与交易事实配合使用 |
| pams_asset_master / pams_asset_alias / asset_classifications / pams_fund_underlying_position | 标的身份、分类及基金底层；行业与主题在分类表中按类型分别约束 |
| valuation_results | 按结果类型区分已发布组合估值与分组收益快照 |
| exposure_engine / lookthrough_state / return_attribution / risk_state | 分析与风控的统一结果 |

收支页消费现金流事实，交易页消费交易事实，持仓页消费快照及交易事实。前端不新增分类、收益、NAV、风险公式或补差逻辑。未知金额、费用、汇率、日期或来源不补零。写入与来源关联规则见 [资料导入与事实写入](IMPORT_AND_FACTS.md)。

来源账本的非零流水按原币方向纳入收支总览和趋势。流入归收入，流出归消费，子类可独立待补。已确认且两端都有有效流水事实的内部划转，按各自的业务日期从收入和消费扣减。候选匹配及现有分类标签不构成配对确认。人民币金额缺少汇率或来源证据时保持未知。

收支总览的分类排行按二级分类展示，展开后显示三级分类及其组内占比。旧记录只有收入或消费标签时，按已知子类归并，未知归属进入分类待补。未配对资金往来按流水方向保留在收入或消费。排行与饼图合计跟随总览统计周期，月度图保留同年走势。总览一次返回本月、本年分类汇总和每个二级分类的月度金额，无需逐分类取流水。

同日且两边原始摘要可核对的跨币种信用卡还款，可在保留两端原币金额和业务日期的情况下人工配对。匹配时使用交易日参考折算筛选候选，差额不产生收入、消费或费用流水。已确认后分别从两侧业务日收支扣除各自的人民币投影。实际手续费以单独证据计入金融费用。

同日一笔银行扣款对应同一发卡行多张卡的合并还款时，可在「待配对」核对并确认整组。各卡须有独立流水和合并还款摘要。同币种要求原币合计等额，跨币种按交易日参考折算核对。确认记录保留各腿原币和来源证据，划转汇总按扣款金额计一组，收支按各腿分别扣除。撤销或证据失效时整组退出划转统计。

手动标为内部转账的单边现金流水在「内部划转 → 待配对」中等待选择另一笔。两侧须有独立的来源凭证、方向相反，且各自只能参加一组有效确认。同币种按等额配对。至少一侧手动标为换汇时，可核对并确认跨日、跨币种换汇，保留两侧原币和入账日，再按原有规则扣减两侧收支。

「个人借入本金」和「归还借款本金」须由用户按流水方向明确确认。在「全部」中可查看，两者计入实际现金净变动，排除在收入、消费和内部划转统计之外。利息和手续费按各自的实际流水分类。

旧账本的待分类流水仍通过 `unclassified_count` 和 `confirmed_subtotal` 表达覆盖情况。

交易复盘中的初始身份、当前身份及最近一次身份变化的原因、触发和证据保存在交易事实中；新库不再创建独立的身份变化历史表。复盘更新不更改交易原始来源及金额，未提供的人工备注保持不变。

隔离新库资产穿透优先读取已保存的基金底层持仓；手工确认的数据优先，按各笔持仓业务日选择，不使用未知日期或未来快照。写入基金底层持仓时保存来源日期，不用持仓日期冒充。未导入底层资料的资产暂时只读配置回退，并在质量结果中标记 `config_fallback`；配置缺日期或晚于持仓日期时不使用并提示。显式资产主数据同步才写入数据库，查询接口不触发写入。该回退是开发阶段过渡，尚不代表配置来源已完全退役。

## 估值、收益和归属

投资持仓列表的市值和占比均按个人持仓市值计算，分母为同一完整列表内可估值的开放投资标的，排除现金、负债及历史参考。浮动盈亏为个人当前市值减个人剩余成本，浮动盈亏率以该剩余成本为分母；零或未知成本不展示比率。员工持股列表第二行展示已核对年内分红和分红占个人持仓成本的比率，详情同时展示浮盈与分红。分红证据不完整时留空，成本非正时仅展示已核对的分红金额。市场对比区的回撤是所选窗口内可比收盘价从高点到末日的变化。

持仓卡右上角的持仓占比汇总当前分类和二级筛选内的标的权重，沿用完整持仓列表的分母。卡片下方的组合占比以全部投资账户净值为分母，分子取卡片所含账户计入该分母的净额。基金总览包含其场外基金和配套活期余额，员工持股扣除专属借款，券商日结使用净清算价值。净值覆盖不全、分母非正或账户范围与卡片净额无法对齐时，组合占比留空。


账户收益单列专属借款后的权益、券商日结净清算价值及共同出资记录。共同出资的当前折算比例只用于当前持仓展示；历史个人收益在各次出资时点的归属核准前显示待核对。券商融资负现金已经包含在官方净清算价值内。

隔离空库的 `market_observations` 统一保存日行情、报价和账户基金估值记录，通过类型区分粒度；业务日、报价时点、来源、估算或确认状态及基金账户锚点仍分别保留。它不替代共享的证券日线和历史汇率。

组合净清算价值 = 总资产 − 总负债。assets_cny 包含持仓及各账户现金；liabilities_cny 包含融资、保证金负债等；net_liquidation_value_cny、as_of、status、quality_flags 同时表达值、日期、完整性与缺口。

子账户走势图采用整户口径和该账户的记账币种。共同出资账户展示整户净值，个人组合 NAV 另按对应日期的归属比例计算。信用卡负债以正数显示，可核对的未出账分期本金与当期账单合并一次；溢缴超过欠款时显示零负债。券商使用同一份收盘报表的净清算价值和净负现金，融资已包含在净清算价值内。

历史金额按业务日期展示。已知的零保留，未知金额留空。余额之间的现金流水能与两端对账时，可推算中间变动日的余额；估算和部分已知分别标示。跨子账户的平台总额须扣除同日、同币种、有依据的其他成员余额，才能归到选中的子账户。

基金和积存金按核对过的成交份额或克数及当日价格估值。整户估值须与已知账户总额对齐，赎回款在确认日至到账前只计一次。只能证明所持基金市值时，单列「持仓估值」，与整户净值分别绘制。

员工持股按认购、交割和借款变动的生效日绘制阶梯。认购款转为股权时只计一次，对应借款从生效日起计入负债。持续有效的余额水平延续，查看时显示原记录日期。只有单日效力的凭证只在当天取值。

分析页的最新已知净资产随读取重新汇总。账户有可用估值时采用其业务日期，其余可用的归档余额按原日期补充最新展示点。账户只计一次，缺来源的账户保留待核验。归档参考只用于展示，自资料所属日起生效；正式发布净值继续使用核验证据。

个人借款按已核准流水的原币分别展示当日借入和归还本金。只有借还流水时，净资产行标记 `personal_loan_coverage.status=principal_movements_only`，已知净资产保留银行现金，个人应付余额待核。区间两端有借款本金净变动的资金账户须从可比账户中剔除。已有负债账户可以通过完整快照的 `liability_scope=all_personal_loan_principal` 声明覆盖当日全部个人应付本金。原件和快照通过复核、该笔负债已按核准口径计入当日净值时，返回 `confirmed` 及原币余额，支持已结清的零余额。

当已有负债账户仅用于保存凭证时，明确覆盖全部私人借款、带有 `point_in_time_only` 的已核准零本金快照，可单独确认当日日终借款余额。该确认只在所列日期生效，组合各账户金额沿用原有汇总。

全体个人资产的已知净资产从上述已核准的日终零本金起，按原币累计随后有原件且经人工核准的借还本金。对尚未计入的可还原应付按估值日汇率扣除，并在 `personal_loan_coverage.principal_reference` 列出起算日、原币余额和实际扣除额。此项只调整参考额，完整净资产和应付余额仍待当日证据。新的本金快照会结束原推算，原件失效、出现负累计或相关币种缺少当日汇率时暂停扣除。

已发生的借还本金在所有原币均已结清且没有冲突时，`recorded_principal_settled` 表示已记录的借还相抵，正式应付余额仍为空。还款日保留当日还本明细，后续无活动日按总览统一展示资料覆盖情况。

所有纳入组合的账户共用最后已知持仓规则。按标的取估值日及以前最后一次同步的持仓，独立读取股票收盘价、基金确认净值或黄金收盘价。已确认现金按余额记录沿用，外币金额按估值日汇率折算。补录影响资料所属日及之后的估值；已核验的完整快照替换旧持仓集合。已知金额按账户计入一次，已核对的整户净值优先。正式 NAV 保留完整范围校验。无法取得任何可用估值时返回空值及估值错误。

投资持仓「全部」卡片按个人投资账户汇总。券商正式收盘的净值、市值、现金和敞口使用同一份报表，其余持仓使用个人份额估值及可用现金证据。正现金计入投资账户现金，负现金和独立投资借款计入融资负债。杠杆倍数为投资总敞口除以正的持仓净值，仅在两项覆盖一致且完整时计算。持仓累计盈亏取在仓标的的个人盈亏。最近一日盈亏按最新有确认记录的业务日期加总，账户与其持仓明细只取一次，部分标的缺该日数据时标记部分。

投资页总收益率以证券、基金、贵金属及可估值股权为范围。沿用估值日及以前最后确认的数量，按该日可得行情或最近已知价格与汇率估值，分别返回持仓确认日和行情日。证券成交、申赎与证券相关的分红、费用按已核验的净额调整收益。缺少行情或成交金额时，收益仅使用前后可比的标的，并返回覆盖状态。银行及券商现金余额、外部出入金、期初现金和融资负债由组合 NAV 与账户收益各自核算。刷新行情只写行情或估值记录。

正式组合估值由独立任务调用同一发布服务。调度传入最低可接受业务日，服务按实际证据日期计算和发布，日期不足或账户范围不全时返回阻断及缺项。收益快照和历史行情补录有各自的检查点，成功发布当前净值不代表历史缺口已补齐。

投资页面读取已发布的派生结果。持仓明细、卡片、估值状态、NAV 和各收益序列在同一数据库快照中生成，并在一个事务中切换版本。NAV、投资收益与账户各自的证据和日期仍由原有服务决定。页面结果单独存放，不作为正式估值、交易或持仓事实。

相关库表变化在原事务中记录待更新标记。调度合并待更新事务，生成 CNY 默认持仓和分析页结果，只清除本次计算可见的标记。未发布新版本时返回上一批并标记待更新。业务日切换或最近一次校验超过五分钟会重新检查文件配置和其他非事务输入。首次生成前或缺少派生结构时使用原读取路径。展示已清仓的扩展持仓仍走原读取路径。

持仓页顶层、收益/NAV 曲线终点、风险分母和配置占比应消费同一有效估值证明。历史发布值不得仅凭相同 XML 覆盖当前结果，还需匹配实际 FX、归属比例和账户输入。持仓账面盈亏、区间收益、NAV 与归因分别追溯；杠杆持仓 gross 市值不是账户净资产，负债不并入现金缓冲，投资入金不当收益。

分类收益序列采用当前持仓覆盖末端时，必须有相同业务日证据，保留此前的历史行及其来源、精度；不得为接平曲线按末端比例缩放或插值历史收益。当前持仓盈亏除以成本是简单持仓回报比，不能据此推导此前日收益率或年化收益；末端数值变化且缺乏完整区间资金流时，这些派生率为未知。末端所需数值全部一致时可沿用原日率和年化率，但数值相等不证明口径或区间完整，须标明原口径未核验。

期间已核对清仓收益按账户、标的、币种隔离，从同一期间内开仓并归零的已验证投资事实计算。成交用含费净现金，另计能归属持有期间的分红和扣税。外币用事实日汇率，个人归属比例只应用一次。期初已有持仓时，须有期初估值才能计算该部分的期间收益。缺少完整估值和资金流时，清仓小计单独返回。持仓页基金的「已知盈亏」由当前浮盈亏加全部历史中已核对的清仓收益组成，完整累计收益率仍待核验。IBKR 已有逐日核验序列时沿用其收益口径。

份额缺失时，只有用户确认全部赎回及完整交易范围，并逐笔绑定既有交易身份，才能对该完整周期使用净现金计算已实现收益；新交易、撤销或证据失效时不再沿用该结论。确认是人工声明而非外部原件认证，不制造份额、不写入新的投资交易，不将累计收益当作跨年期间收益。银行理财按资产类型单独返回清仓小计，不并入基金小计或未经验证的收益率曲线。

人民币基金分类历史用已核实来源的申赎和份额变动回放，按账户与标的身份分组。按确认的单位净值所属日估值，赎回退出后保留此前的持有期间。份额与现存快照核对，申赎净现金计作基金范围的流量。基金全集、期初或流水覆盖未核准时，明确展示覆盖子集的估值曲线和缺口。同一曲线的基金范围固定，缺净值时保留空点，缺口间存在无法估值的净流量时停止串联收益。历史净值可通过 `POST /api/prices/refresh/fund-nav-history?start=YYYY-MM-DD` 预览，显式 `preview=false` 才归档正式净值。

以克计量的人民币黄金持仓用上金所 Au99.99 已发布收盘价估值，持仓、贵金属收益和组合净值共用该价格。银行持仓快照保留为数量、成本和银行参考市值的来源证据。无成交时，持仓变化来自金价。买卖以含费的实际扣款或到账更新现金，按成交后数量估值，差额自然反映在净值中。已含于净现金的手续费只计一次。没有持仓数量证据的日期保持缺口。 若已核验的首笔买入与后续持仓的标的、数量及含费成本相符，且期间无其他持仓变动证据，可从买入日开始读时重建收益，不回写持仓。首日收益以实付金额为基准。

IBKR 日结、估值与收益保留以下边界：

- 官方 NAV = 现金 + 证券 + 应计利息 + 应计股息 + 明确列出的其他 NAV 成分；Long/Short、分项及子成分交叉核对，不重复相加，已结算进现金的利息不再扣一次。
- 期间盈亏 = 期末 NAV − 独立期初 NAV − 期间净外部流量。证据应为完全同范围桥接，或连续且端点一致的逐日 ChangeInNAV；缺期初、缺日、未知字段均不补零，YTD 入金不能替代任意期间流量。
- 旧 return_ratio 是简单资本回报比：期间盈亏 /（期初 NAV + 期间净外部流量），不是 TWR、MWR 或个股持仓收益率。资本基数不为正时无定义，前端显示 --，不能制造 0%。后端显式提供 return_capital_base/cny。
- 新日结证明及展示 FX 均可用时，前端直接绑定 NAV、期间盈亏和资本基数；不能用“证券＋现金”或“NAV－入金”覆盖。未启用时保持原兼容路径，缺字段不得将新口径零值化。
- 官方账户基币按同业务日内部 FX 折算展示币，缺 FX 不默认为 1，也不取未来值。期末外币盈亏乘期末 FX 是展示折算，不等于人民币期间投资收益；原币逐项估值与基币再折算的差异独立桥接。
- gross assets/liabilities 须有官方总 Long/Short 证据，不能按净 NAV 正负伪造。完整 performance 保持完整账户语义；portfolio_account 是独立的组合身份/归属 join，身份、FX、归属均有证明才启用，比例只应用一次，零归属不显示虚构收益率。
- 账户总览保留平台原始值，primary 余额绑定共享确认值和历史 FX；输入证据变化使旧审批失效。沿用上一有效历史值时返回原日、请求日、过期状态，不能假称当日确认。持仓盈亏投影与 NAV 投影分别处理。
- IBKR 持仓卡片按合约号和原币对照已发布 Flex 持仓、成交与现金事实。数量和流水范围吻合时，累计盈亏为浮动盈亏加 FIFO 已实现盈亏及税后股息，人民币显示使用持仓估值汇率。行情更新只改变浮动部分。

## 账户快照与收益

资产总览的净资产走势按日期用连续实线连接已知估值，缺少估值的日期保留空值。区间内含部分账户估值时，图表标为「已知净资产走势」，点选金额可查看当日计入的账户数和含估算的账户数。顶部金额和曲线终点使用同一批数据。

银行外币现金在周末缺少当日汇率时，可在「已知净资产」中展示本周五以来最近一次有凭证的折算值。账户必须有可追溯的原币余额，期间余额和资金归属一致。图上标注汇率日期，此类历史参考单独计入估算，正式日终估值与可比账户计算仍要求各自的日期证据。

区间变化取期末减期初，变化率以正的期初净资产为分母。年初至今从上年 12 月 31 日日终起算，近 1 月从上月对应日（最晚为月末）起算，近 1 周从七天前起算。资产总览仅在两端整体净资产均可用、账户覆盖和估值口径一致时展示变化额及变化率。其他情况显示区间日期及原因。接口中的可比账户明细供对账使用。

已验证的完整账户快照已包含现金、证券及负债；用两个完整快照的差额更新账户净值时，不得再加入已体现在现金余额中的交易与出入金。现金余额从已确认的现金成员及同日有来源汇率计算，负债按负号计入；快照范围、币种或汇率未知时保持未知。

基金或理财的赎回份额已确认、净款尚未到达银行时，按已核验的净款计入在途资产，到账日由银行余额承接。信用卡分期有合同、放款、逐期入账和剩余本金证据时，按出账日还原未出账本金；同日账单欠款与未出账本金分别核对范围后合计。

账户净值变动不等于投资收益：账户入金、提现和内部转账不得当成收益。单笔已核对的资金流只能作为已观察明细，不能证明整个期间流水完整。当期间资金流或期初本金口径缺少完整证据时，日收益、总收益和收益率保持未知，不根据净值差额或空流水补零。配置中的旧报告金额仅作未核验背景，不覆盖来源已证实的账户快照。

## 每日收益窗口

### 隔离候选：计算版本与多来源输入

`076_valuation_input_evidence.sql` 已纳入空库初始化；来源直写、IBKR/TradingView 持仓以及价格、基金和银行余额写入路径在隔离库记录版本，尚未据此执行存量库迁移或线上切换。结果身份包含结果类型、范围、账户（持仓必填）、业务日期、本位币、计算版本、结果哈希和输入指纹；每个结果可记录多条持仓、交易、行情或汇率输入，相同输入也可由不同结果引用。输入保留来源表及键、可选来源版本、业务日、观测时点、质量与内容快照；没有证据允许留空，不能倒填。

候选服务在同一事务内先写输入再写结果，通过延迟外键、版本锁和不可变触发器保持原子性、幂等及禁止事后追加。低层记录方法仍接收调用方提供的数据，只用于隔离构造，不能证明外部来源真实性。持仓绑定方法按 `account-import:` 账户事务锁，从数据库加锁读取并哈希实际持仓、交易事实、行情和汇率；持仓原始行以精确值保存在不可变证据内，旧行变更后仍可查看原值。结果使用账户与持仓名称构成的稳定逻辑范围、业务日独立区分版本；同一键的新行只标为 `replacement_candidate`，不自动继承旧来源，也不证明经济标的相同。

持仓行存在 `source_item_id` 时，候选自动读取该来源及批次，要求账户一致、批次已发布、明细已确认、资料类型及日期范围不冲突；其他已知来源明细只能显式引用并经过同样检查，可按来源明细反查已记录的结果版本。`cash` 批次仅在明细明确为 `action=balance` 且结果为现金持仓时可作为余额来源，收支流水不能冒充持仓余额。批次范围只能排除冲突，不能证明明细日期准确。结果哈希表示持仓快照内容，不证明这些输入实际参与了原始计算。持仓与交易账户必须一致，持仓、行情和汇率日期必须与结果日一致，交易不得晚于结果日；缺失来源为未知，不伪造确认或补写旧关系。上游缺乏原始明细、交易集或报价身份时，可按角色记录无引用的未知输入。

持仓行上的主来源仅标记为 `holding_creation_source`，不自动代表当前值来源。实际计算明确传入 `current_source` 时，同一来源可同时承担创建和当前来源两个角色。当前来源读取只考虑与当前持仓完整内容哈希匹配且内部证据可核验的版本；来源缺失或未经核验返回 `unknown`，存在不同来源则返回 `ambiguous`。`recorded` 仅表示已记录的来源，不能单凭这一标签证明计算输入集合完整或已财务核准。

价格刷新、黄金现价、基金净值和银行余额写持仓时使用同一账户事务锁；隔离模式在同一事务内留存更新前后版本。当前接口缺少可核验的行情或账单明细身份时，输入记录为未知，不将首次持仓来源冒充本次估值依据；数值未变化时不撤销既有来源。价格及基金估值在隔离模式重新核对来源持仓身份、数量与成本，遇到陈旧输入或新日期已有冲突持仓即阻断，不覆盖并发更正。上述保护尚未授权生产部署或历史迁移。

核验函数检查内部指纹；来源变更、消失、账户或日期冲突分别使记录失效或返回不一致。输入内容相同也不证明集合完整，报价时点缺失、交易或持仓质量未知时不得认定准确日结。正式接入前仍须证明输入确由计算流程使用，并与来源明细发布门禁对齐；现有金额、历史数据和线上路径不受影响。

亚太收盘后更新亚太收盘价、基金/港股预估及美股预估；美股收盘后确认相关美股、港股、QDII 和场外基金收益。北京时间 07:00 后前日收益进入历史，今日窗口滚动。具体市场及基金状态依赖实际来源日期，不由页面时钟制造确认。 已公布基金净值另每 30 分钟同步一次，重读最新持仓，使用供应商净值日落库；收盘任务跨日停止时，基金同步仍可在周末补上新录入持仓或迟到净值。基金单独同步不发布组合收益快照。每轮核对最近 14 天的已公布基金单位净值。Tushare 缺日期时查东方财富正式净值，按净值日保留来源。同日已有确认净值不覆盖，日期缺失单独标记。历史份额无法由同日快照或已确认交易与持仓核对时，仅存净值，不生成历史持仓估值。

银行卡转账、券商到账及投资资金进出不得进入投资收益。调度日期、高水位、重试和官方日结发布规则见 [券商同步与对账](BROKER_SYNC_AND_RECONCILIATION.md)。

## 每日汇兑归因

return_attribution.daily_fx_attribution 是只读解释，不是 NAV、账目、累计盈亏或收益率的新来源。证券汇兑估算与账户净汇兑分开：证券可随上市地日期更新，账户桥接必须使用同一已发布日结的相邻有效账户日；输出请求日、核对日和期初日，不能把不同日期确认值合为今日收益。

| 模块 | 责任 |
| --- | --- |
| ibkr_daily_close_read.load_evidence | 校验清单和原文字节哈希，不下载、刷新或入账 |
| ibkr_daily_fx | 复用日结账户/日期/NAV门禁，读取原币证券、正负现金、现金分类、ConversionRate及严格历史FX |
| daily_fx_bridge | 纯 Decimal 计算，不访问文件、网络、数据库或 endpoint |
| return_attribution | 只附加解释字段，保留原金额及原维度 |
| 前端 | 绑定解释及状态，不重算汇率、收益、融资或差额 |

R 为每单位原币折人民币的日终汇率，P 为证券市值，C 为有符号现金，T 为交易现金本金（卖出正、买入负，不含费用），I 为现金收益，E 为有符号费用，F 为净外部资金流入。

```text
价格收益 = (P1 - P0 + T) × R1
证券汇兑 = P0 × (R1 - R0)
现金汇兑 = C0 × (R1 - R0)
净汇兑 = 证券汇兑 + 现金汇兑
收益/费用 = I × R1 / E × R1
未解释原币现金 = C1 - C0 - T - I - E - F
资产现金期间盈亏 = (P1+C1)×R1 - (P0+C0)×R0 - F×R1
```

这是日终平移约定，不是逐笔成交时点的已实现换汇收益。融资负现金自然抵消证券敞口，不再额外扣融资本金。换汇、衍生品、未知现金分类及官方 NAV 的应计/其他成分保留独立差额；未证明原币归属的应计不能归入净汇兑。

CNY 自身汇率严格为 1；人民币基金净值已含底层 FX 时不再叠加。工具计价币不等于经济敞口币。原币至报表本位币使用同日官方 ConversionRate，再乘同日内部本位币至 CNY 汇率，保留日期/来源/组合方式。内部历史 FX 恰好同日，不取未来、最新或上一日替代。缺身份、现金、日期、分类或 FX 返回 null 和覆盖原因；舍入差、未知活动及原币现金残差保留，状态容差不修改金额或吞掉未知活动。

## 账户期间资金流覆盖

账户净值是完整快照中资产、现金和负债的净额，买卖或入出金已经反映在快照内，不得再次叠加。证券市值、现金和非现金负债分开展示；负债按负值计入净额。

期间收益只在起止快照、账户及期间资金流均有完整来源时计算：期末净值减期初净值再减外部净流入。普通账户可以使用经人工确认的来源报告，核对原件哈希、账户、日期、逐笔事实及来源，多份报告须连续覆盖且去重；未识别的非现金转移或持仓调整、原件变动、缺少同日汇率或范围证据时收益为未知。人工报告的身份认证状态为未知，不等同于官方证明。IBKR 官方报告可通过完整 NAV 分项及外部转移桥接证明期间，但事实发生冲突仍须保守处理。

配置的初始资金只有提供业务日期、与独立期初快照一致且整个期间来源覆盖时才能计算该期间累计收益；结果标记为锚点期间，不声称是成立以来收益。收益率是期间盈亏除以期初净值加期间净流入，不是时间加权或资金加权收益率。仅观察到的现金流不能证明期间完整，静态配置也不能覆盖真实净值。

组合估值的日收益仅在所有纳入净值的账户都有同一期间的已核验净流与起止快照时汇总；账户金额须与组合净值一致、归属比例只计算一次。缺任一账户、期间、来源或汇率时，组合日收益为 null，实际证明为零时才显示零。已发布估值与来源哈希一起保存；空账户和空持仓不产生完整零净值。

摘要接口区分未提供、未刷新、已确认及估算收益：空资产范围、缺行情或缺收益时对应值为 null；现金余额不自动代表零收益。原始市值可证时仍展示市值，缺失或过期行情不会被转换成零涨跌；估算收益标记 estimated。

IBKR 非人民币账户的多日资金流按逐日原文桥接及当日有来源汇率换算，再汇总为人民币；原币期间净流为零不代表换算后净流为零。逐日证明可来自同一完整原件，也可来自逐日独立核对并发布的账户快照原件。该路径要求每个自然日的报表完整且连续、账户与期初期末一致，缺一日、缺汇率或超过 366 日的期间为未知；单一汇总桥不能替代逐日证据。

同一账户和日期已有独立发布的券商账户来源时，须与期末原件中的逐日桥和相邻 NAV 对齐；来源损坏、账户冲突、同日多份歧义或金额不一致时，期间收益保持未知，不能回退到通用人工覆盖报告掩盖冲突。没有独立日来源且期末原件本身具有完整逐日证据时，可按该原件计算；券商已发布端点存在但期间超过 366 日无法逐日核查时，通用覆盖也不能绕过这一限制。

对于已确认完整申赎周期且补充证据同时给出份额与某日单位净值的银行理财，可复用交易来源校验和周期重放，将该日估值作为账户的已知部分。若同一标的已有持仓估值则不再叠加；证据撤销或存在冲突时不采用。单日估值不证明账户完整，也不自动延续到其他日期。
