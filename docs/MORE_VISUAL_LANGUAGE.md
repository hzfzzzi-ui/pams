## 已确认的具体根因

- 旧更多页自行定义Inter回退，缺少投资页的SF Pro Text；主菜单16px/600，而投资持仓名为16px/900。高级链接14px/600、summary为14px/400，形成同级异重。
- 既有全局details[open] summary规则带important，外层展开时会同时污染内层summary的颜色与背景；只在更多页覆盖，不修改其他页面折叠样式。
- 低频模板的moreHub网格规则特异性更高，之前局部display:block没有生效。局部提升作用域后明确使用紧凑文档流，不移除其他低频页模板。
