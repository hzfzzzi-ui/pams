# 更多页：沿用投资页的视觉语言

更多页沿用投资页已建立的金融终端风格，不建立另一套主题。功能层级保持导入资料/账户管理/研究、异常才出现的待处理、默认折叠高级工具和全部目标链接；菜单样式不承载业务JS、财务口径或投资/收支页面的变化。实现及验证记录见[PR82](https://github.com/hzfzzzi-ui/pams/pull/82)。

## 从投资页提炼

| 维度 | 投资页实际规则 | 更多页应用 |
| --- | --- | --- |
| 字体 | body使用pams-font-sans，包含Inter及SF Pro Text/Segoe UI回退 | 使用同一变量，不另写字体栈、不新增字体或CDN |
| 主名称 | 持仓名16px/900，行高1.28，主文本色 | 一级菜单完全一致；标题18px/900，不使用资产大数字的hero字号 |
| 信息层级 | 名称重、元数据小且弱；金额才有数值层级 | 二级工具14px/700，分组标题13px，辅助信息12px/700；菜单不使用数字等宽字体 |
| 颜色 | canvas #05070a，主文#f3f6fb，辅助色#6f7888 | 引用同一canvas/text/line变量，不另设偏蓝底色；告警用warning，不用收益红绿装饰 |
| 结构 | 扁平列表、细分隔线、无悬浮卡片 | 保留列表和折叠，不新增菜单卡片、图标色块或功能说明段落 |
| 密度 | 手机内容最大430px，实际横向留白8/10px | 宽屏仍430px，沿用同一gutter变量；一级行60px、工具行52px，长文字自然换行 |
| 选中态 | 蓝色标明导航/可操作状态，非大块填色 | 保留底部导航原样；展开只改变小箭头，工具文字不随外层折叠一起染蓝 |

数值强调与菜单导航是不同语义：投资净值的大字号/系统数字字体不复制到更多标题，收益正负色不复制到普通入口。这里抽取的是层级与组件角色，不是把所有文字设成同一字号。

## 已确认的具体根因

- 旧更多页自行定义Inter回退，缺少投资页的SF Pro Text；主菜单16px/600，而投资持仓名为16px/900。高级链接14px/600、summary为14px/400，形成同级异重。
- 既有全局details[open] summary规则带important，外层展开时会同时污染内层summary的颜色与背景；只在更多页覆盖，不修改其他页面折叠样式。
- 低频模板的moreHub网格规则特异性更高，之前局部display:block没有生效。局部提升作用域后明确使用紧凑文档流，不移除其他低频页模板。

## 验证契约

投资参考取相同生成手机CSS的真实选择器，用无金额名称探针读取计算样式，不依赖生产API、市场波动或外部字体下载。页面底稿与数据恢复备份分开，不以样式测试证明资产核准。

320/390/1280逐项比较body字体/底色、主名称字体/字号/字重/行高/颜色与横向留白；覆盖正常、警告、状态读取失败、高级展开、系统信息、NAV读取失败、键盘焦点、长标题和零横向溢出。固定替身只允许GET，不能冒充手机Safari/Tailscale或真实外部字体的验证。键盘焦点必须以Tab/Shift+Tab实际切换，不以鼠标模式下的focus()代替。

CSS须可解析且限定body.page-more，回归保留公共与生成手机样式。候选web构建/配置smoke及与修改前候选的逐文件比较分开记录；只有更多HTML/CSS改变才通过样式变更范围门禁，业务JS、投资/收支及公共/手机CSS逐字节保留。不因局部样式修改重复采集重型NAV；旧金融证据不升级为新的生产财务核准。
