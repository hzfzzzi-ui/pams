# Changelog

## [1.1.0] - 2026-02-15

### ✨ 新功能
- 完成 Vue 3 前端重构，使用 Composition API + TypeScript
- 实现 5 个核心页面：总览、持仓、收支、策略、观察池
- 集成 Element Plus UI 组件库（暗色主题）
- 集成 Chart.js 4.4 数据可视化
- 实现 Pinia 状态管理
- 支持中文本地化显示

### 🐛 Bug 修复
- 修复页面切换无法正常工作的问题
- 修复 API 响应格式不匹配导致的数据显示错误
- 修复持仓数据类型字段 (rows vs holdings)
- 修复收支/NAV/回撤系列数据提取错误
- 修复总览页路由导航问题（空路径处理）
- 修复 Chart.js 控制器注册缺失问题

### 🎨 UI/UX 改进
- 完整的中文标签映射（平台、账户、资产类型）
- 响应式布局，支持桌面和移动端
- 统一的暗色主题设计
- 流畅的页面切换动画
- KPI 卡片实时数据展示

### 📊 数据展示
- **总览页**：5 个 KPI 卡片 + 4 个图表 + 风险告警 + 系统状态
- **持仓页**：30 条持仓记录，支持类型筛选和排序
- **收支页**：收支统计卡片 + 趋势图表
- **策略页**：IPS 参数 + NAV/回撤曲线 + 风险事件
- **观察池页**：完整的 CRUD 功能

### 🔧 技术栈
- Vue 3.4.21 (Composition API)
- TypeScript 5.4.2
- Vite 5.1.6
- Element Plus 2.6.0
- Chart.js 4.4.1
- Pinia 2.1.7
- Vue Router 4.3.0
- Axios 1.6.7
- Day.js 1.11.10

### 📝 已知问题
- Sass 使用了遗留 API（有弃用警告，不影响功能）
- favicon.ico 缺失（404 错误，不影响功能）
- 页面切换时会重新加载数据（已禁用缓存确保稳定性）

### 🔄 迁移说明
- 从原生 HTML/JS 迁移到 Vue 3 框架
- API 路径保持不变 (`/api/*`)
- 数据模型完全兼容后端 API
- 支持开发服务器代理配置
